# 🤖 Bot 99Freelas - Assistente Inteligente de Freelancing

Assistente automatizado para monitoramento, triagem cirúrgica, precificação estratégica e geração de propostas de alta conversão para o **99Freelas**.

---

## 🎯 Objetivo
Acelerar a conquista dos primeiros projetos e avaliações 5 estrelas no 99Freelas através de:
- **Filtro Inteligente**: Análise semântica dos projetos para economizar conexões limitadas.
- **Precificação Estratégica**: Valor competitivo para novos perfis sem desvalorizar o trabalho.
- **Copywriting Persuasivo**: Propostas personalizadas focadas na dor específica de cada cliente.
- **Atendimento e Negociação**: Scripts e automação de conversa quando o cliente responder.
- **Painel de Controle**: Gestão visual em Kanban das propostas e tarefas.

---

## 🛠️ Stack Tecnológica & Skills Integradas

O projeto utiliza o ecossistema do **Antigravity** e skills especializadas integradas na pasta `.agents/skills`:

- **`sales-automator`**: Geração de propostas de alta conversão e follow-ups.
- **`pricing-strategy`**: Cálculo de precificação e elasticidade de proposta.
- **`browser-harness`**: Automação segura do navegador com sessões persistentes.
- **`customer-support`**: Suporte consultivo e alinhamento de expectativas no chat.
- **`no-free-work`**: Proteção contra escopo inflado e pedidos extras.
- **`async-python-patterns`**: Execução assíncrona com Python 3.
